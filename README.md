# ⏰ 재고 소진 예측 & 자동 발주 알림 타이머

최근 판매 속도를 기반으로 품절 임박 시점을 예측하고, 자동으로 발주서를 생성해주는
재고 관리 도구입니다.

---

## 🎯 주요 기능

* 최근 판매 속도를 기반으로 **품절 임박 D-Day**를 예측합니다.
* 목표 안전재고 기준 **부족 수량**을 자동 계산합니다.
* 공급처 전달용 **자동 발주서**를 생성합니다.

## 💻 사용 방법

1. 현재 **재고 및 최근 판매 이력 엑셀**을 업로드합니다.
2. 목표 안전재고 기준을 설정합니다.
3. 품절 임박 D-Day와 부족 수량을 확인합니다.
4. 자동 생성된 발주서를 다운로드합니다.

## 🛠️ 기술 스택

* **Language**: Python
* **Web Framework**: Streamlit
* **Data Processing**: Pandas, OpenPyXL

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```
